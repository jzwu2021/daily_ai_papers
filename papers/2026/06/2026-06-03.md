# AI Papers Digest — 2026-06-03

Selected recent arXiv papers.

## Overview

The newest arXiv batch is heavily focused on turning language models into more durable systems: agents that learn across tasks, reason with externalized state, operate in personalized tool environments, and are evaluated in realistic settings instead of static benchmarks. A second strong theme is grounded multimodality, with new work on video reasoning, low-level vision evaluation, and benchmark design for embodied or device-rich environments. Overall, the paper set suggests a shift from asking whether models can act at all to asking whether they can act safely, adaptively, and reproducibly over long horizons.

## Papers

### 1. ClinEnv: An Interactive Multi-Stage Long Horizon EHR Environment for Agents
Date: 2026-06-01
URL: https://arxiv.org/abs/2606.02568
Summary: ClinEnv evaluates LLMs as attending physicians in a longitudinal inpatient simulation where models must query specialized agents and then make sequential, irreversible care decisions. It matters because it replaces static medical QA with a much more realistic test of information gathering, management decisions, and long-horizon reasoning under uncertainty.

### 2. SafeSteer: Localized On-Policy Distillation for Efficient Safety Alignment
Date: 2026-06-01
URL: https://arxiv.org/abs/2606.02530
Summary: SafeSteer argues that safety alignment should make sparse, localized changes to model behavior instead of globally trading off capability against safety, and trains with penalties focused on safety-relevant tokens. The significance is that it offers a concrete path to lowering the alignment tax without relying on large general-purpose datasets or heavy auxiliary reward modeling.

### 3. MCP-Persona: Benchmarking LLM Agents on Real-World Personal Applications via Environment Simulation
Date: 2026-06-01
URL: https://arxiv.org/abs/2606.02470
Summary: MCP-Persona introduces a benchmark for agent use of personalized MCP tools across applications like Slack, Reddit, Xiaohongshu, and Feishu, where agents must act in account-specific environments rather than generic search tasks. This is important because real personal-agent deployment depends on handling individualized state, permissions, and context that existing benchmarks often ignore.

### 4. AGENTCL: Toward Rigorous Evaluation of Continual Learning in Language Agents
Date: 2026-06-01
URL: https://arxiv.org/abs/2606.02461
Summary: AGENTCL evaluates whether language agents can accumulate reusable experience over streams of related tasks instead of repeatedly solving each task from scratch. It matters because persistent improvement is one of the core promises of agentic systems, and this paper gives a cleaner way to measure transfer gains and interference over time.

### 5. Harness-1: Reinforcement Learning for Search Agents with State-Externalizing Harnesses
Date: 2026-06-01
URL: https://arxiv.org/abs/2606.02373
Summary: Harness-1 trains a search agent inside an environment that manages working memory, verification records, evidence links, and context rendering, leaving the policy to focus on semantic search decisions. The broader significance is that long-horizon agent performance may improve when routine bookkeeping is moved out of the model and into structured external state.

### 6. SMH-Bench: Benchmarking LLM Agents for Environment-Grounded Reasoning and Action in Smart Homes
Date: 2026-06-01
URL: https://arxiv.org/abs/2606.01912
Summary: SMH-Bench uses an executable smart-home simulator with 1,100 tasks to test whether LLMs can reason over user intent, preferences, scheduling, and multi-device interactions in realistic homes. This matters because environment-grounded evaluation exposes weaknesses in ambiguity handling, automation logic, and personalized reasoning that API-mapping tests can miss.

### 7. VLMs are Good Teachers for Video Reasoning via Adaptive Test-Time Optimization
Date: 2026-06-01
URL: https://arxiv.org/abs/2606.02564
Summary: This paper uses vision-language models as teachers that extract task rules and provide differentiable rewards to guide video generation models during test-time optimization. It is notable because it reframes multimodal reasoning as a teacher-student control problem, where perception models supervise process quality rather than directly solving the task.

### 8. LL-Bench: Rethinking Low-Level Vision Evaluation in the Era of Large-Scale Generative Models
Date: 2026-06-01
URL: https://arxiv.org/abs/2606.02535
Summary: LL-Bench builds a large human-annotated benchmark for low-level vision tasks and shows that current evaluation metrics often disagree with expert judgments about restored-image quality. The paper matters because generative models are increasingly used for restoration and editing, but the field still lacks reliable ways to measure pixel-level quality and failure modes.

### 9. MMG2Skill: Can Agents Distill In-the-Wild Guides into Self-Evolving Skills?
Date: 2026-06-01
URL: https://arxiv.org/abs/2606.01993
Summary: MMG2Skill studies how agents can convert noisy, multimodal human guides from the web into executable skills and then revise those skills from trajectory-level feedback. The contribution is important because scalable agent learning may depend less on hand-authored demonstrations and more on turning messy real-world procedures into reusable, self-improving capabilities.

## Themes

- Agent research is moving toward continual learning, reusable memory, and structured external state instead of one-shot problem solving.
- Evaluation quality is becoming a first-class issue, especially for safety, personalized tools, smart homes, and medical decision workflows.
- Practical agent benchmarks increasingly focus on realistic environments with irreversible actions, user-specific context, and long horizons.
- Multimodal systems are being trained and judged with more explicit process supervision, especially in video reasoning and grounded execution.
- Safety and reliability work is shifting from broad abstract principles toward narrower interventions that preserve capability while improving control.
