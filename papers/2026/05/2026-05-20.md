# AI Papers Digest — 2026-05-20
Selected recent arXiv papers.

## Overview
Recent arXiv papers show the agent stack maturing from isolated demos into a full systems problem spanning skills, execution environments, memory, safety, and observability. Several papers focus on how to evaluate or monitor long-horizon behavior rather than treating final answers as the only metric that matters. Multimodal and embodied work is also becoming more action-centric, emphasizing structured control, perception-action loops, and fine-grained evidence use.

## Papers
### 1. SkillGenBench: Benchmarking Skill Generation Pipelines for LLM Agents
Date: 2026-05-18
URL: https://arxiv.org/abs/2605.18693
Summary: SkillGenBench isolates skill generation itself by evaluating how systems turn raw repositories and documents into reusable, executable skill artifacts under a standardized protocol. That matters because many agent architectures now depend on reusable skills, and the field needs a way to measure whether those skills are correct and transferable rather than only scoring downstream task success.

### 2. EnvFactory: Scaling Tool-Use Agents via Executable Environments Synthesis and Robust RL
Date: 2026-05-18
URL: https://arxiv.org/abs/2605.18703
Summary: EnvFactory proposes an automated framework that builds executable environments and training trajectories for tool-use agents, aiming to reduce dependence on costly real APIs, brittle simulators, and over-scripted synthetic data. Its significance is practical: robust tool agents need cheap, diverse, and realistic environments for reinforcement learning, and this work targets that infrastructure bottleneck directly.

### 3. LongMINT: Evaluating Memory under Multi-Target Interference in Long-Horizon Agent Systems
Date: 2026-05-18
URL: https://arxiv.org/abs/2605.18565
Summary: LongMINT benchmarks memory-augmented agents in interference-heavy settings where facts evolve, overlap, and compete across long horizons instead of staying static and independent. This is important because real deployed agents fail less from simple forgetting than from conflicting updates and aggregation errors over time, so the benchmark targets a more realistic failure mode.

### 4. Position: A Three-Layer Probabilistic Assume-Guarantee Architecture Is Structurally Required for Safe LLM Agent Deployment
Date: 2026-05-18
URL: https://arxiv.org/abs/2605.18672
Summary: This position paper argues that no single guardrail can certify safe agent behavior because semantic intent, environmental validity, and dynamical feasibility become knowable at different execution stages. The contribution is conceptually important for agent deployment: safety needs staged contracts across the stack, not a single alignment filter placed at the prompt boundary.

### 5. Monitoring the Internal Monologue: Probe Trajectories Reveal Reasoning Dynamics
Date: 2026-05-18
URL: https://arxiv.org/abs/2605.18549
Summary: The paper studies hidden-state probe trajectories across reasoning traces and finds they can predict future model behavior more effectively than relying on one static snapshot or visible chain-of-thought alone. This matters for safety and auditing because it suggests a path toward monitoring large reasoning models even when their explicit reasoning text is incomplete or misleading.

### 6. Aurora: Unified Video Editing with a Tool-Using Agent
Date: 2026-05-18
URL: https://arxiv.org/abs/2605.18748
Summary: Aurora pairs a tool-augmented vision-language agent with a unified video diffusion transformer so that raw user requests can be translated into structured editing plans with the right references and spatial controls. The broader value is that it closes a major product gap between what users naturally ask for and what multimodal generation systems actually need to perform precise edits.

### 7. ESI-Bench: Towards Embodied Spatial Intelligence that Closes the Perception-Action Loop
Date: 2026-05-18
URL: https://arxiv.org/abs/2605.18746
Summary: ESI-Bench reframes spatial intelligence as an embodied problem in which agents must act to reveal hidden structure rather than passively answer from fixed observations, and it evaluates that idea across a broad OmniGibson benchmark. The paper is notable because it pushes spatial reasoning toward the real setting robots face, where the right next action is part of perception itself.

### 8. Vision-OPD: Learning to See Fine Details for Multimodal LLMs via On-Policy Self-Distillation
Date: 2026-05-18
URL: https://arxiv.org/abs/2605.18740
Summary: Vision-OPD tackles the regional-to-global perception gap in multimodal LLMs by distilling the model’s stronger performance on evidence-centered crops back into full-image understanding. This is significant because many multimodal failures come from attention and evidence localization rather than raw recognition limits, so the method targets a concrete bottleneck in fine-grained visual reasoning.

## Themes
- Agent research is increasingly focused on durable system components such as skills, memory, and executable environments.
- Safety is shifting from single-pass guardrails toward staged architectures and internal monitoring of reasoning processes.
- Benchmarks are becoming more realistic by modeling interference, long horizons, and embodied action rather than static QA settings.
- Multimodal progress depends on translating messy human intent into structured controls that generative systems can reliably execute.
- Fine-grained perception and observability are emerging as central constraints for deploying agentic and multimodal systems.
