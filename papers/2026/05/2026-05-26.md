# AI Papers Digest — 2026-05-26

Selected recent arXiv papers.

## Overview

This paper set is unusually focused on making agentic and reasoning systems more reliable in practice. Several papers study skill acquisition, memory safety, recovery, and context management for long-horizon agents, while others probe core LLM behavior through scaling, reward design, and long-context evaluation. Together, they suggest the field is shifting from asking whether agents can work at all to asking how they can improve, recover, and stay trustworthy under real operating constraints.

## Papers

### 1. SkillOpt: Executive Strategy for Self-Evolving Agent Skills
Date: 2026-05-22
URL: https://arxiv.org/abs/2605.23904
Summary: SkillOpt treats a skill document as trainable external state for a frozen agent and applies bounded text edits that are only accepted when they improve held-out validation performance. The idea matters because it turns prompt-like skill artifacts into something closer to a disciplined optimizer target, which could make agent improvement more reproducible and cheaper to deploy.

### 2. From Raw Experience to Skill Consumption: A Systematic Study of Model-Generated Agent Skills
Date: 2026-05-22
URL: https://arxiv.org/abs/2605.23899
Summary: This paper studies the full lifecycle of model-generated agent skills, from experience generation through extraction to downstream consumption, across multiple domains. Its main contribution is showing that skills help on average but also create meaningful negative transfer, which is a practical warning for anyone building general-purpose skill libraries.

### 3. MemAudit: Post-hoc Auditing of Poisoned Agent Memory via Causal Attribution and Structural Anomaly Detection
Date: 2026-05-22
URL: https://arxiv.org/abs/2605.23723
Summary: MemAudit asks which stored memories actually caused a harmful agent behavior after the fact, combining counterfactual influence scoring with anomaly detection over the memory graph. This is important because persistent memory is becoming a standard agent feature, and post-hoc auditing is a missing piece for security and forensic debugging.

### 4. DART: Semantic Recoverability for Structured Tool Agents
Date: 2026-05-22
URL: https://arxiv.org/abs/2605.23311
Summary: DART formalizes when a failed structured tool agent can safely recover from a local checkpoint without invalidating already committed downstream work. The significance is that practical agent runtimes need more than rollback mechanics—they need semantic criteria for when partial recovery is actually safe.

### 5. Parallel Context Compaction for Long-Horizon LLM Agent Serving
Date: 2026-05-22
URL: https://arxiv.org/abs/2605.23296
Summary: This paper proposes parallel summarization-based context compaction so long-horizon agents can keep bounded context without blocking inference for long periods or producing highly unpredictable summary sizes. It matters because context management is becoming an infrastructure problem for deployed agents, not just a prompt-engineering detail.

### 6. LLMs as Noisy Channels: A Shannon Perspective on Model Capacity and Scaling Laws
Date: 2026-05-22
URL: https://arxiv.org/abs/2605.23901
Summary: The authors model LLM training as information transmission over a noisy channel and argue that performance can degrade when scaling increases noise faster than useful signal. This is notable because it offers a unified explanation for non-monotonic effects such as overtraining and quantization degradation that simpler scaling laws do not capture well.

### 7. Metacognition as Reward: Reinforcing LLM Reasoning via Knowledge and Regulation Signals
Date: 2026-05-22
URL: https://arxiv.org/abs/2605.23384
Summary: Metacognition-as-Reward adds process-level reward signals for task knowledge coverage and regulation rather than relying only on final-answer correctness or heavily customized rubrics. The work matters because reasoning improvements may depend on teaching models how to monitor and steer their own problem-solving process, not just optimize end outcomes.

### 8. OpenSkillEval: Automatically Auditing the Open Skill Ecosystem for LLM Agents
Date: 2026-05-22
URL: https://arxiv.org/abs/2605.23657
Summary: OpenSkillEval builds realistic downstream tasks and compares community-contributed skills under unified settings across models and agent frameworks. Its practical value is that the open skill ecosystem is growing faster than its evaluation standards, and users need a way to compare skills on cost-performance tradeoffs instead of anecdote.

### 9. Positional Failures in Long-Context LLMs: A Blind Spot in Reasoning Benchmarks
Date: 2026-05-22
URL: https://arxiv.org/abs/2605.23170
Summary: This paper shows that many long-context reasoning evaluations fail to control where the target task appears in context, and that some models degrade sharply when the same task moves from the end to the middle. It is important because strong long-context headlines can hide brittle positional behavior that matters in real retrieval and agent settings.

### 10. CRONOS: Benchmarking Counterfactual Physical Consistency in Video Models
Date: 2026-05-22
URL: https://arxiv.org/abs/2605.23699
Summary: CRONOS tests whether video models preserve the same underlying physical event when viewpoint, scene, appearance, or object category changes. The benchmark is significant because future world models need more than photorealistic outputs—they need counterfactually stable physical understanding.

## Themes

- Agent research is centering on operational reliability: memory auditing, checkpoint recovery, and bounded-context serving.
- Skills are becoming a first-class systems abstraction, but they need better optimization and evaluation methods.
- Reasoning progress is increasingly tied to process supervision and calibration rather than final-answer scoring alone.
- Long-context performance still has hidden failure modes that standard benchmarks can miss.
- Multimodal world-model evaluation is moving toward counterfactual physical consistency instead of surface realism.
